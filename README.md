# Reading Roadmap · 读书路线规划 Skill

给定一本书或在线教程，**先问清你的阅读目的**，再产出按目标重排的章节阅读顺序、逐日学习计划，以及一份可打卡的 HTML 导读卡。

不是把目录复述一遍——是先问"你为什么要读"，再决定先读哪一章。

## 它解决什么问题

- 你拿到一本书/教程，但**不想从第一章开始读**
- 读完就忘，因为没有目标、没有节奏
- 想看"对我有用的部分"，而不是把整本啃完
- 想每天花 15 分钟慢慢推进，但不知道怎么拆

## 工作方式

1. **三问画像**：先问三个问题（阅读目的 / 领域熟悉度 / 每日可投入），给选项让你选，不猜
2. **摸结构**：抓取真实的章节地图与依赖关系
3. **按目的定序**：根据"目的 × 书类型 × 章节依赖"重排阅读顺序
4. **逐日化**：拆到每一天（读 + 写/测），每周一个复盘日
5. **交付导读卡**：独立 HTML 打卡页，每行一个章节链接 + 勾选框，进度自动保存在浏览器

## 安装

**方式一：git clone（推荐，一条命令）**

```bash
git clone https://github.com/qgpuerr/reading-roadmap.git <你的技能目录>/.user_skills/reading-roadmap
```

**方式二：直接复制**

把 `reading-roadmap` 文件夹放进 `<你的技能目录>/.user_skills/` 下即可，无需命令行。（从别人那里拿到文件夹，或下载 ZIP 解压后，都是这么放。）

（`.user_skills` 是客户端工作区下的用户自定义技能目录，和已有自定义技能放在同一层即可。）

## 使用

直接对助手说这类话即可触发：

- "帮我给这本书排个阅读顺序，我不想从第一章读"
- "按我的目标安排一下阅读路线"
- "具体到每一天，每天 15 分钟"
- "给我做一份阅读路线导读卡"

助手会**先问你三个问题**（目的 / 熟悉度 / 时间），确认后再给路线。

## 范围（v1）

- 支持：有可访问在线章节的文章 / 教程 / 文档 / 开源仓库（docsify、GitBook、GitHub 等）
- 暂不支持：本地电子书（EPUB/PDF）、纸质书（无在线版时降级为文字路线）
- 不做：读后摘要、书评、内容提炼

## 目录结构

```

├── assets/

└── references/

    ├── routing.md              类型 × 目的决策矩阵
    ├── rationale.md            定序依据（学习科学）
    ├── pacing.md               逐日化规则
    ├── link-authoring.md       在线站点链接生成与验证
    └── deliverables.md         导读卡生成契约与校验清单
```
