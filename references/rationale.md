# 定序依据（rationale）

路线不是拍脑袋，依据三层：材料结构、学习科学、目标画像。

## 1. 材料依赖结构

- 教程/文档通常自带依赖（"每部分是下一阶段阶梯"式自述）。
- Gagné 前提分析（Learning Hierarchy）：后一能力依赖前一能力，先学前置再学目标。
- 识别可跳读章节（环境配置、综述、番外）与必读核心。

## 2. 学习科学通用原理

- **最近发展区（Vygotsky）**：内容难度应略高于当前水平、够得着；对零基础者先补地基（概念弹药），不要直接上最终案例。
- **认知负荷（Sweller）**：一次只处理一个主题；15 分钟只读一小节 + 一个微目标，不贪多。
- **主动学习（Freeman 2014 PNAS 元分析）**：主动学习比讲授提升显著（约 +0.47 SD、挂科率 OR≈1.95）——所以逐日表强制"读 + 写/测"结构。
- **检索练习与分散练习（Dunlosky 2013 高效用）**：每天小剂量 + 每周复盘自测，优于一次性突击。
- **先行组织者（Ausubel）**：先给章节地图和"为什么要这么读"，再进细节；导读卡顶部即地图。

## 3. 目标画像

- 目的排序决定权重：求职 → 面试高频 + 作品；解决问题 → 倒推；系统掌握 → 全序。
- 时间预算决定颗粒度：15 分钟 → 小节级 + 微目标；周末集中 → 整章 + 动手。

## 用法

写路线或导读卡时，在页脚/说明里引用依据（一行即可，如"按依赖序 + 检索练习原则拆分"），不展开学术细节。
