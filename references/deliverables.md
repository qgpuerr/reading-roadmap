# 导读卡交付规范（reading-roadmap）

> **当前范围：仅支持在线文章/教程/文档。** 目标必须有可访问的在线章节（docsify/GitBook/GitHub 仓库等）。本地电子书（EPUB/PDF）与纸质书形态为**预留扩展**：模板已保留 `.local/.badge/.loc` 样式，但本版生成时**不使用**，目标无在线版时如实告知并降级为对话内文字路线，不假装支持。

读前路线规划的最终交付物：对话内 renderer 表格（轻量场景）或独立 HTML 导读卡（长期打卡场景）。本文档是独立 HTML 版（`assets/guide-template.html`）的生成契约。

## 1. 模板占位符

| 占位符 | 含义 | 生成要求 |
| --- | --- | --- |
| `{{BOOK_TITLE}}` | 书名 | 同时用于 `<title>` 与 hero 标题 |
| `{{BOOK_SUBTITLE}}` | 画像摘要 | 一句话：目的排序 · 领域熟悉度 · 每日时间 |
| `{{META_TAGS}}` | meta 标签组 | 天数 / 每日节奏 / 复盘日 / 存档说明 |
| `{{TOTAL_DAYS}}` | 总天数 | 进度条分母，须与表格行数一致 |
| `{{STORAGE_KEY}}` | localStorage key | 形如 `roadmap_<书拼音>_v1` |
| `{{WEEKS}}` | 周分组 + 表格 HTML | 见第 2、3 节 |
| `{{RULES}}` | 节奏与规则文字 | 含链接形态说明 |
| `{{SOURCES}}` | 页脚来源 | 书/教程的真实来源与链接 |

## 2. 表格结构与链接形态

固定 6 列（table-layout:fixed，min-width:760px）：`天 / 主题 / 怎么做 / 当日微目标 / 定位 / 打卡`。

「定位」列**当前版本只有一种形态：在线链接**：

1. 在线：`<a class="lk" href="https://..." target="_blank" rel="noopener">章节名</a>` — 链接必须来自真实抓取或源码推算并逐条验证，禁止凭印象拼 URL；能精确到小节锚点（`?id=`）就精确到小节；**一律新窗口打开（`target="_blank"` + `rel="noopener"`），禁止原窗口跳转**。
2. 预留（本版不使用）：本机 `file://`（PDF 可带 `#page=N`）、纸质书页码文字 `<span class="loc">`。样式已在模板中，契约见第 3 节。

## 3. 本机/纸质形态的硬限制（预留扩展，本版不使用）

- 一旦启用本机形态：`file://` 链接只在**用户本机、文件路径不变**时有效；发布线上（doubao-html 等 https 域）或移动/重命名文件后立即失效；必须带 `.local` + `.badge`「本机」标注；交付说明写明失效条件。
- 纸质书无链接可跳，只能用页码文字定位，不得留空。

## 4. 打卡交互（模板已内置，无需改动）

- 勾选框 `input.ck[data-day]`，每天一行一个；行内 `tr` 由 JS 加 `done` 态。
- 状态存 `localStorage`（key 为 `{{STORAGE_KEY}}`），顶部进度条实时更新，页脚「重置打卡」带确认。
- JS 为 IIFE，放 body 末尾，不依赖 DOMContentLoaded；无 JS 时页面仍可读（表格静态呈现）。

## 5. 生成与校验清单

交付前逐项核对：

- [ ] 占位符全部替换，无残留 `{{ }}`
- [ ] 勾选框数量 = 总天数；总天数 = 表格行数
- [ ] 在线链接逐个实际抓取/验证可达；能精确到小节锚点就精确；全部 `target="_blank"` 新窗口
- [ ] 无 emoji；无口号文案；**规则说明 ≤1 句，能省则省**；视觉 token 用模板默认（白底、#0F766E、PingFang 栈）
- [ ] 结构校验（HTMLParser：无 unclosed/mismatch）+ 脚本语法校验（node --check）
- [ ] 截图自检（shot.py）失败时按 html skill 规则跳过，改走结构 + 语法校验，并在交付说明注明
- [ ] 交付说明写清：本机链接失效条件、未实现能力、来源

## 6. 降级链

独立 HTML 不可行 → 对话内 renderer 表格 → 结构化文字表格。任何层级都不得把链接列留空或编造 URL。
